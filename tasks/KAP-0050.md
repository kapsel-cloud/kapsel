# Historical Hosted Sandbox Umbrella

Status: superseded. KAP-0070 closed the hosted experiment through its offline fallback, and KAP-0073
removed the deployable implementation.

Historical owners: [sandbox API](../docs/SANDBOX_API.md),
[sandbox deployment](../docs/SANDBOX_DEPLOYMENT.md), [KAP-0070](KAP-0070.md), and
[KAP-0073](KAP-0073.md).

## Historical scope

The umbrella joined:

- fixed anonymous HTTP admission and projection;
- one-active scheduling and bounded retention;
- native runner process separation and handoff;
- synthetic Kubernetes targets and fixed policy;
- authority staging;
- public receipt projection; and
- exact cleanup and absence evidence.

It preserved KAP-0038 result meaning: infrastructure and transport failures were never receiver
results, and `UNKNOWN` remained explicit.

## Security requirements

The design required bounded input and output, saturation before dispatch, per-run ownership,
cross-run isolation, no credential or signing-material disclosure, explicit traffic cutoff, and
cleanup distinct from operation outcome. These controls were never accepted as a complete live
hosted deployment.

## Closure

No hosted implementation work remains. Removed sandbox packages, deployment assets, provider
configuration, and public endpoints are not current interfaces or architecture. Historical fixtures
and archive tags remain engineering evidence only.

## Residual risk

The archived design did not prove production operation, hard multi-tenancy, complete hosted
isolation, disaster recovery, or supported availability.
