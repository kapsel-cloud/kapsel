# Historical Provider-Neutral Runner Handoff

Status: complete historical implementation at revision `b36af376066b002c33ef584187a726e49634337f`.
KAP-0073 removed it with the sandbox.

Owners: [historical sandbox deployment](../docs/SANDBOX_DEPLOYMENT.md),
[KAP-0038](../docs/experiments/KAP-0038-kubernetes-effect-gateway-boundary.md), and
[sandbox removal](KAP-0073.md).

## Boundary

The runner handoff separated HTTP/service state from one native `Application` process:

```text
sandbox service
  -> bounded authenticated descriptor handoff
       -> native runner identity and cgroup
            -> kapsel::Application
                 -> result and receipt handoff
```

The service transferred fixed read-only inputs by descriptor, not caller-selected paths. The runner
validated command, environment, identity, lease, parent-death, cgroup, and input bounds before
opening `Application`. Private authority and signing material never entered public request or
projection fields.

## Recovery

A durable invocation marker distinguished safe first execution from same-operation recovery. After
an ambiguous process loss, a newly fenced runner reused existing durable state and reconciled rather
than blindly issuing another mutation. Stale leases and late publication were rejected. Terminal
result and receipt handoff remained separate from sandbox cleanup state.

## Evidence

Native Linux tests covered descriptor identity, parent death, cgroup membership, capability bounds,
empty/malformed inputs, deadlines, lease expiry, late publication, secret redaction, oversized
input, explicit `UNKNOWN`, and process-loss recovery. Focused and default gates passed for the exact
historical revision.

## Closure

The handoff is archived evidence only. It defines no provider command, live deployment route, public
interface, or resident-service dependency. Do not move its scheduler, lease, cgroup, staging, or
handoff machinery into root `kapsel` or `kapseld`.

## Residual risk

The local handoff did not establish hosted isolation, provider enforcement, complete cleanup,
availability, or production safety.
