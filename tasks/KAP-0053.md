# Historical Hosted Provider Topology

Status: retired. No provider resource, credential, endpoint, image, DNS record, or live authority
from this route remains active.

This packet is historical engineering context for the removed sandbox. It is not a deployment guide,
current task, supported topology, or source of resident-service requirements.

Owners: [historical sandbox deployment](../docs/SANDBOX_DEPLOYMENT.md),
[technical scope](../docs/SCOPE.md), and [sandbox removal record](KAP-0073.md).

## Historical design

The proposed hosted route separated:

- fixed public admission/projection;
- scheduler and controller state;
- short-lived runner authority;
- synthetic Kubernetes targets;
- provider bootstrap and teardown authority; and
- cleanup/absence evidence.

The runner composition used fixed authority channels, explicit identities, bounded command and
environment fields, descriptor handoff, and one concrete `kapsel::Application`. It did not create a
generic provider or capability interface.

## Evidence disposition

Source-level and deterministic tests covered parts of authority composition, runner identity,
command/environment bounds, image construction, and cleanup planning. Infrastructure enforcement,
live isolation, failure recovery, and complete provider teardown were never accepted as a current
supported deployment.

Historical image and topology revisions remain available through Git history and sandbox archive
tags. Non-reproducible provider-account state and proposed infrastructure inventory are not part of
this technical record.

## Closure

KAP-0073 removed the deployable sandbox package, provider assets, and active hosted gates. The
resident service must not reuse this topology's HTTP admission, scheduler, authority staging,
provider bootstrap, cleanup controller, or second SQLite store.

## Residual risk

The historical design was never qualified as a complete live hosted system. Its archived source may
contain useful implementation evidence, but it carries no current security, availability,
compatibility, deployment, or cost claim.
