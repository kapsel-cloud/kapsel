## Finite result

One exact clean revision exposes the unchanged fixed `v1` JSON vocabulary through a same-origin
website boundary. A visitor chooses only `healthy` or `unavailable-image` plus an idempotency key.
The server chooses every target and authority input, runs the real `Application` against one
dedicated synthetic cluster, intentionally loses the native runner at the owned ambiguous seam,
reconciles the same operation without a blind second mutation, returns the real receiver-bounded
result and frozen receipt, and tracks cleanup separately.

At most one run owns active or cleanup capacity. Exact UID/owner absence, runner retirement, and
journal handoff precede reuse. The proof uses no customer data, production workload, arbitrary
Kubernetes input, or caller/provider credential.

Controller-process restart with the same validated state remains supported. Controller-host or
storage loss has no visitor continuity: independently withdraw traffic, manufacture no outcome, tear
down every dedicated synthetic and provider resource, prove absence independently of the lost
database, recreate clean and stopped, validate readiness and abuse controls, then explicitly reopen.
Old locators, projections, and receipts may be lost.

1. Delete backup/restore-only code, schema, gateway bridge, tests, and planned commands while
   keeping every retained focused gate green.
2. Prove the three failure domains remain distinct:
   - runner-process loss reconciles the same operation;
   - controller-process restart works only with the same validated state; and
   - host/storage loss appends no outcome, receipt, `service_failed`, `not_attempted`, cleanup

6. Produce the smallest authenticated reproducible host bundle for the retained controller, runner,
   authority, policy, cleanup, and traffic-cutoff composition.
7. Pass focused sandbox lanes, the complete default gate, and fresh architecture, correctness,
   security, and privacy review from one clean revision.

runtime/kernel escape remains possible; anonymous abuse can deny fair availability; cleanup can

utility or production safety.
